## 완료된 기능 (Phase 2)

### ✅ 2. TAA (전술적 자산 배분) 도구
**완료일**: 2025-11-01

**파일**:
- `momentum_calculator.py` - 모멘텀 계산 엔진
- `app.py` - 3개 새 페이지 추가

**기능**:

#### 1. Momentum Allocation (모멘텀 기반 국가별 비중 계산기)
- 3/6/12개월 모멘텀 수익률 계산
- 모멘텀 계수 선택 (1, 2, 3)
- Dual 모멘텀 옵션 (3M+12M 평균)
- 추천 비중 자동 계산 및 시각화
- 커스텀 티커 지원

**계산 방식**:
```python
# 1. N개월 수익률 계산
momentum = (current_price - price_n_months_ago) / price_n_months_ago * 100

# 2. 모멘텀 스코어 적용
scores = (1 + momentum/100) ^ power

# 3. 비중 계산
weights = (scores / scores.sum()) * 100
```

#### 2. Absolute Momentum (절대 모멘텀 신호)
- 자산별 매수/중단 신호 표시
- 6개월 기준 (변경 가능)
- 신호 > 0%: 🟢 Buy
- 신호 < 0%: 🔴 Stop
- 시장 상태 요약 (강세 자산 비율)

#### 3. Asset Allocation (자산 배분 시뮬레이터)
- 주식:채권 비율 슬라이더 (50:50 ~ 80:20)
- 코어:새틀라이트 비율 슬라이더 (50:50 ~ 100:0)
- 현재 보유 자산 분석
- 리밸런싱 워크플로우 가이드

**데이터 소스**:
- yfinance를 통한 실시간 시장 데이터
- 기본 티커: SPY, 069500.KS, ASHR, VGK, TLT, 148070.KS

## 투자 철학 & 전략

### 핵심 원칙
1. **펀더멘털 중시** - 기업 실적이 주가를 이끔
2. **모멘텀 중요** - 초과 유동성 시대에 가격 과민 반응
3. **베타 투자** - 현금보다 자산 보유 필요

### 투자 전략
**"코어&새틀라이트 + 전술적 자산 배분(TAA) + 모멘텀"**

#### 자산 배분 범위
1. **주식:채권 비율**
   - 기본: 7:3
   - 최소: 5:5 (채권 최대)
   - 최대: 8:2 (주식 최대)

2. **코어:새틀라이트 비율**
   - 기본: 7:3
   - 최소: 10:0 (코어 최대)
   - 최대: 5:5 (새틀라이트 최대)

#### 코어 자산
- 미국 인덱스 (S&P500)
- 한국 인덱스 (KOSPI)
- 중국 인덱스 (CSI300)
- 유럽 인덱스
- 미국 국채, 한국 국채

#### 새틀라이트 (알파 투자)
- 에너지 산업 (원유, 가스, 탱커)
- 원자재 (금, 구리)
- 우량/저평가 기업

#### 의사결정 방식
- **국가별 비중**: 3/6/12개월 모멘텀 기반 기계적 계산
- **절대 모멘텀**: 6개월 상승률 기준 매수/중단 판단
- **리밸런싱**: 매월 말

## 다음 구현 기능 (Phase 2)

### 우선순위 1: 핵심 TAA 도구

#### 1. 모멘텀 기반 국가별 비중 계산기
**목적**: 코어 자산(인덱스) 비중 자동 계산

**입력**:
- 각 인덱스 티커 (S&P500, KOSPI, CSI300, etc.)
- 모멘텀 기간 선택 (3/6/12개월)
- 모멘텀 계수 (2 or 3)

**출력**:
- 국가별 추천 비중 (%)
- 비중 시각화 (파이차트)
- 현재 보유 vs 추천 비중 비교

**계산 방식**:
```python
# 1. 각 인덱스의 N개월 수익률 계산
# 2. 모멘텀 스코어 = 수익률 ^ 계수
# 3. 비중 = 스코어 / 전체 스코어 합
```

**파일**: `momentum_calculator.py`, `app.py` (새 페이지)

---

#### 2. 절대 모멘텀 신호 대시보드
**목적**: 매수/중단 신호 자동 판단

**입력**:
- 자산 리스트 (인덱스 + 새틀라이트)
- 기준 기간 (기본 6개월)

**출력**:
- 자산별 신호 테이블
  - 6개월 수익률
  - 신호 (🟢 매수 / 🔴 중단)
  - 상태 변화 알림
- 신호 히스토리

**계산 방식**:
```python
if 6개월_수익률 > 0:
    신호 = "매수"
else:
    신호 = "중단"
```

**파일**: `momentum_signals.py`, `app.py` (새 페이지)

---

#### 3. 자산 배분 시뮬레이터 (리밸런싱 도구 통합)
**목적**: 비중 조절 및 리밸런싱 계획

**기능**:
- **비중 조절 슬라이더**
  - 주식:채권 (50:50 ~ 80:20)
  - 코어:새틀라이트 (100:0 ~ 50:50)

- **리밸런싱 계산**
  - 현재 보유 비중 자동 계산
  - 목표 비중과 비교
  - 매수/매도 필요 금액 계산
  - 실행 체크리스트

- **시나리오 분석**
  - "만약 주식 비중을 70%로 변경하면?"
  - 과거 데이터 기반 예상 성과

**출력 예시**:
```
[리밸런싱 계획]
현재: 주식 65% / 채권 35%
목표: 주식 70% / 채권 30%

필요 조치:
- 국채 ETF $500 매도
- S&P500 ETF $300 매수
- 에너지 ETF $200 매수
```

**파일**: `asset_allocation.py`, `app.py` (새 페이지)
