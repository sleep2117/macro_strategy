**목적**: 모멘텀 스코어 계산 및 추천 비중 산출

| CSI300 | =Price_Data!H4 | =IF(B4>0,"🟢","🔴") | =IF(B4>0,B4,0) | =(1+D4/100)^$K$2 | =E4/SUM($E$2:$E$5)*100 | |

**파라미터 설정**:

- 절대모멘텀 🔴 → 해당 자산 제외

## 4. Asset_Allocation (자산 배분 결정)

**목적**: 주식/채권, 코어/새틀라이트 비율 결정

### 구조

| A | B | C | D |
|---|---|---|---|
| **자산 배분 결정** | | | |
| | | | |
| **1. 주식 vs 채권** | | | |
| 주식 비중 (%) | **70** | ← 입력 (50~80) | |
| 채권 비중 (%) | =100-B4 | 자동 계산 | |
| | | | |
| **판단 근거** | | | |
| 경기 전망 | 확장 | ← 입력 | |
| 금리 전망 | 인하 | ← 입력 | |
| 시장 모멘텀 | 강세 | ← 자동 (Momentum_Calc 참조) | |
| | | | |
| **2. 코어 vs 새틀라이트** (주식 내) | | | |
| 코어 비중 (%) | **70** | ← 입력 (50~100) | |
| 새틀라이트 비중 (%) | =100-B12 | 자동 계산 | |
| | | | |
| **판단 근거** | | | |
| 고확신 종목 수 | 3 | ← 입력 | |
| 알파 기회 | 보통 | ← 입력 | |

### 입력 가이드라인

**주식 비중 선택**:
- 80%: 강세장 + 경기 확장 + 금리 인하
- 70%: 보통 (기본)
- 60%: 혼조장 + 경기 불확실
- 50%: 약세장 + 경기 침체

**코어 비중 선택**:
- 100%: 고확신 종목 없음
- 80%: 고확신 종목 1~2개
- 70%: 고확신 종목 3~5개 (기본)
- 60%: 고확신 종목 5~7개
- 50%: 고확신 종목 8개 이상

## 8. Rebalancing (리밸런싱 실행)

**목적**: 현재 보유 vs 목표 비중 비교, 매수/매도 금액 계산

### 8-1. 현재 보유 현황

| A | B | C | D | E | F |
|---|---|---|---|---|---|
| **종목** | **Ticker** | **보유 수량** | **현재가** | **평가금액** | **비중** |
| S&P500 | SPY | 10 | =Price_Data!C2 | =C2*D2 | =E2/SUM($E$2:$E$15) |
| KOSPI | 069500.KS | 350 | =Price_Data!C3 | =C3*D3 | =E3/SUM($E$2:$E$15) |
| ... | | | | | |
| **합계** | | | | =SUM(E2:E15) | =SUM(F2:F15) |

### 8-2. 목표 보유 현황

| H | I | J | K |
|---|---|---|---|
| **목표 비중** | **목표 금액** | **차이** | **조치** |
| =Core_Allocation!C8 | =Core_Allocation!D8 | =I2-E2 | =IF(J2>50000,"매수 ₩"&J2,IF(J2<-50000,"매도 ₩"&ABS(J2),"유지")) |
| =Core_Allocation!C9 | =Core_Allocation!D9 | =I3-E3 | =IF(J3>50000,"매수 ₩"&J3,IF(J3<-50000,"매도 ₩"&ABS(J3),"유지")) |
| ... | | | |

**로직**:
- 차이 > 50,000원 → 매수
- 차이 < -50,000원 → 매도
- 그 외 → 유지 (소액은 수수료 부담)

### 8-3. 매매 주문서

| A | B | C | D | E | F |
|---|---|---|---|---|---|
| **순서** | **종목** | **매매** | **금액** | **예상 수량** | **비고** |
| 1 | KOSPI | 매도 | 500,000 | =D2/Price_Data!C3 | 먼저 매도 |
| 2 | S&P500 | 매수 | 800,000 | =D3/Price_Data!C2 | 현금 확보 후 매수 |
| ... | | | | | |

**매매 순서 원칙**:
1. 모든 매도 먼저
2. 현금 확보 후 매수

## 🔧 엑셀 설정 및 팁

### 조건부 서식

**1. 절대 모멘텀 표시**
- 조건: =C2="🟢"
- 서식: 배경색 초록
- 조건: =C2="🔴"
- 서식: 배경색 빨강

**2. 수익률 색상**
- 조건: >0
- 서식: 글자색 파랑
- 조건: <0
- 서식: 글자색 빨강

**3. 리밸런싱 조치**
- 조건: =ISNUMBER(SEARCH("매수",K2))
- 서식: 배경색 연한 초록
- 조건: =ISNUMBER(SEARCH("매도",K2))
- 서식: 배경색 연한 빨강

### 데이터 유효성 검사

**1. 주식 비중 (Asset_Allocation!B4)**
- 유효성 검사: 정수
- 데이터: 50 ~ 80
- 오류 메시지: "50~80 사이 값을 입력하세요"

**2. 코어 비중 (Asset_Allocation!B12)**
- 유효성 검사: 정수
- 데이터: 50 ~ 100
- 오류 메시지: "50~100 사이 값을 입력하세요"

### 이름 정의

편리한 수식 작성을 위해 이름 정의:
- `총자산` = Dashboard!B3
- `주식비중` = Asset_Allocation!B4
- `코어비중` = Asset_Allocation!B12
- `모멘텀계수` = Momentum_Calc!K2

### 보호 설정

**보호할 셀**: 수식이 있는 모든 셀
**입력 허용 셀**:
- Price_Data: C열, D열, E열, F열 (가격 입력)
- Asset_Allocation: B4, B12 (비중 결정)
- Satellite_Selection: A, D, E열 (종목, 확신도, 비중)
- Rebalancing: C열 (보유 수량)

## 💡 활용 팁

### Tip 1: 분할 매수/매도
- 리밸런싱 금액이 큰 경우 (100만원 이상)
- 2~3일에 걸쳐 분할 실행
- 시장 충격 최소화

### Tip 2: 슬리피지 대비
- 목표 금액의 ±5% 허용
- 정확한 수량보다 대략적 배분 우선
- 소액(5만원 이하)은 무시

### Tip 3: 수수료 절감
- 거래 횟수 최소화
- 변동폭 작은 자산은 리밸런싱 스킵
- 차이가 10% 이상일 때만 조정

### Tip 4: 데이터 백업
- 매월 말 엑셀 파일 복사 저장
- 파일명: `Portfolio_2025-01.xlsx`
- 월별 스냅샷 유지

### Tip 5: 시나리오 분석
- 엑셀 시나리오 기능 활용
- 주식 비중 60/70/80 시나리오 저장
- 빠른 비교 가능
