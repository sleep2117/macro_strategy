# TAA (전술적 자산 배분) 도구 사용 가이드

**작성일**: 2025-11-01

---

## 개요

3개의 새로운 TAA 페이지가 포트폴리오 대시보드에 추가되었습니다:
1. **Momentum Allocation** - 모멘텀 기반 국가별 비중 계산
2. **Absolute Momentum** - 절대 모멘텀 매수/중단 신호
3. **Asset Allocation** - 자산 배분 시뮬레이터 & 리밸런싱 도구

---

## 1. Momentum Allocation (모멘텀 기반 국가별 비중 계산기)

### 사용 목적
코어 자산(인덱스)의 국가별 추천 비중을 모멘텀 기반으로 자동 계산합니다.

### 사용 방법

1. **설정 선택**:
   - **Momentum Coefficient**: 모멘텀 가중치 (1, 2, 3)
     - 1 = 선형 (낮은 집중도)
     - 2 = 제곱 (중간 집중도) - **권장**
     - 3 = 세제곱 (높은 집중도)

   - **Primary Period**: 주요 모멘텀 기간 (3, 6, 12개월)
     - 6개월 권장

   - **Dual Momentum**: 3개월+12개월 평균 사용 여부
     - 단기+장기 모멘텀 조합 시 체크

2. **티커 커스터마이징 (선택사항)**:
   - 기본값 사용 가능
   - 다른 ETF/인덱스로 변경 가능
   - 예: SPY → VOO, ASHR → MCHI

3. **"Calculate Allocation" 버튼 클릭**

### 결과 해석

**Recommended Allocation (파이 차트)**:
- 각 국가/자산별 추천 비중 (%)
- 모멘텀이 높을수록 큰 비중

**Momentum Returns (막대 차트)**:
- 각 자산의 N개월 수익률
- 녹색: 상승 모멘텀
- 빨강: 하락 모멘텀

**Detailed Analysis (테이블)**:
- 3M/6M/12M Return: 각 기간별 수익률
- Recommended Weight: 계산된 추천 비중

### 활용 예시

```
결과:
S&P500: 40%
Europe: 30%
KOSPI: 20%
CSI300: 10%
US Treasury: 0%  (음수 모멘텀)

→ 미국/유럽 중심 배분, 채권은 제외
```

## 2. Absolute Momentum (절대 모멘텀 신호)

### 사용 목적
각 자산의 매수/보유 여부를 절대 모멘텀 기준으로 판단합니다.

### 사용 방법

1. **Momentum Period 선택**: 3, 6, 12개월 중 선택
   - 기본: 6개월 권장

2. **티커 설정** (선택사항)

3. **"Get Signals" 버튼 클릭**

### 신호 해석

**🟢 Buy (매수/보유)**:
- N개월 수익률 > 0%
- 상승 추세 중
- 안전하게 보유/매수 가능

**🔴 Stop (중단/회피)**:
- N개월 수익률 < 0%
- 하락 추세 중
- 비중 축소 또는 회피 고려

### 활용 전략

```
6개월 절대 모멘텀 기준:

S&P500: +12.5% → 🟢 Buy
KOSPI: -3.2% → 🔴 Stop
CSI300: +8.1% → 🟢 Buy
US Treasury: +2.3% → 🟢 Buy

→ S&P500, CSI300 보유/매수
→ KOSPI 비중 축소 고려
→ 채권은 안전 자산으로 유지
```

### Market Breadth (시장 폭)
- 강세 자산 비율이 50% 이상: 강세장
- 강세 자산 비율이 50% 미만: 약세장/조정

## 3. Asset Allocation (자산 배분 시뮬레이터)

### 사용 목적
목표 자산 배분 비율을 설정하고 리밸런싱 계획을 수립합니다.

### 사용 방법

1. **현재 배분 확인**:
   - 파이 차트: 자산 유형별 현재 비중
   - 테이블: 자산별 금액 및 비중

2. **목표 배분 설정**:
   - **Stock Allocation**: 50~80% (슬라이더)
     - 50%: 방어적 (채권 50%)
     - 70%: 중립적 (채권 30%)
     - 80%: 공격적 (채권 20%)

   - **Core Allocation**: 50~100% (슬라이더)
     - 100%: 순수 인덱스 투자 (새틀라이트 0%)
     - 70%: 균형 (새틀라이트 30%)
     - 50%: 적극적 알파 추구 (새틀라이트 50%)

3. **목표 금액 확인**:
   - 각 카테고리별 목표 금액 자동 계산

### 리밸런싱 워크플로우

```
1단계: Momentum Allocation 페이지에서 추천 비중 확인
   → 예: S&P500 40%, Europe 30%, KOSPI 20%, CSI300 10%

2단계: Asset Allocation 페이지에서 목표 비율 설정
   → 예: Stock 70%, Bond 30%, Core 70%

3단계: 계산
   - 총 자산: ₩36,749,069
   - 주식 목표: ₩25,724,348 (70%)
   - 채권 목표: ₩11,024,721 (30%)
   - 코어 목표: ₩25,724,348 (70%)
   - 새틀라이트 목표: ₩11,024,721 (30%)

4단계: 현재 보유 vs 목표 비교
   - 주식 현재: 65% → 70%로 증가 필요
   - 채권 매도: ₩1,837,453
   - 주식 매수: ₩1,837,453

5단계: Momentum 비중으로 주식 내 배분
   - S&P500 매수: ₩735,000 (40%)
   - Europe 매수: ₩551,000 (30%)
   - KOSPI 매수: ₩367,000 (20%)
   - CSI300 매수: ₩184,000 (10%)

6단계: 증권사에서 거래 실행

7단계: 거래 완료 후 CSV 업데이트 → 대시보드 새로고침
```

## 통합 사용 시나리오

### 시나리오 1: 월말 정기 리밸런싱

**날짜**: 매월 마지막 거래일

1. **Absolute Momentum 확인**
   - 6개월 신호로 각 자산 매수/중단 판단
   - 🔴 Stop 신호 자산은 제외

2. **Momentum Allocation 계산**
   - 🟢 Buy 신호 자산만으로 비중 계산
   - Coefficient 2, Period 6M 사용

3. **Asset Allocation에서 목표 설정**
   - 시장 상황에 따라 Stock:Bond 비율 조정
   - 강세장: 75:25
   - 중립: 70:30
   - 약세장: 60:40

4. **리밸런싱 실행**

### 시나리오 2: 시장 급락 시

**상황**: KOSPI -10% 급락

1. **Absolute Momentum 재확인**
   - 모든 자산의 신호 체크
   - 🔴 Stop 증가 여부 확인

2. **Asset Allocation 방어적 조정**
   - Stock 비율 70% → 60%로 하향
   - Bond 비율 30% → 40%로 상향

3. **Momentum Allocation으로 주식 내 재배분**
   - 하락한 자산 비중 축소
   - 강한 자산으로 집중

### 시나리오 3: 새 알파 기회 발견

**상황**: 에너지 섹터 강세 전환

1. **Asset Allocation에서 Satellite 증가**
   - Core 70% → 60%
   - Satellite 30% → 40%

2. **Satellite 자산에 에너지 ETF 추가**
   - 커스텀 티커에 XLE 등 추가
   - Absolute Momentum으로 신호 확인

3. **비중 반영하여 매수**

## 주의사항

### 데이터 업데이트
- yfinance는 실시간 데이터 제공
- 장 마감 후 사용 권장
- 한국 시간 기준 새벽에 미국 데이터 최종 확정

### 티커 정확성
- 한국 ETF: `.KS` 또는 `.KQ` 접미사 필요
- 예: KODEX KOSPI = 069500.KS
- 티커 오류 시 데이터 미수신

### 모멘텀 계수
- 너무 높은 계수(3)는 과도한 집중 초래
- 기본 2 사용 권장
- 분산 중시 시 1 사용

### 신호 맹신 금지
- 모멘텀은 후행 지표
- 펀더멘털 분석과 병행 필수
- 거시 경제 상황 고려

## FAQ

**Q: 모멘텀이 전부 음수면?**
A: 전체 시장 약세. 채권/현금 비중 확대 고려

**Q: Dual Momentum과 Single Momentum 차이?**
A: Dual은 단기(3M)+장기(12M) 평균, 변동성 완화

**Q: 티커를 찾을 수 없다고 나옴?**
A: yfinance에서 지원 안 되는 티커. 대체 ETF 사용

**Q: 리밸런싱 주기는?**
A: 월말 권장. 너무 잦은 리밸런싱은 수수료 과다

**Q: 한국 주식 개별 종목도 가능?**
A: 가능. 티커에 `.KS` 또는 `.KQ` 추가
예: 삼성전자 = 005930.KS
